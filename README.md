# Employee Data Analysis

Data analysis project using Python, Pandas, and Matplotlib to analyze employee salaries, departments, and city distribution. The project focuses on data cleaning, exploratory data analysis (EDA), KPI generation, and data visualization to extract meaningful business insights.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib

## Project Objectives

* Clean and preprocess employee data
* Analyze salary information
* Evaluate department performance
* Analyze employee distribution across cities
* Generate business insights through data visualization

## Key Performance Indicators (KPIs)

* Total Salary
* Average Salary
* Highest Salary
* Lowest Salary
* Department with Highest Average Salary
* City with Highest Number of Employees

## Visualizations

* Number of Employees by Department
* Average Salary by Department
* Employee Distribution by City

## Data Cleaning

* Removed missing values
* Removed duplicate records

## Key Insights

* Identified the department with the highest average salary.
* Determined the city with the largest employee population.
* Compared employee distribution across departments.
* Analyzed salary trends and workforce distribution.
