# employee-data-analysis
Data analysis project using Python, Pandas and Matplotlib to analyze employee salaries, departments and city distribution.

# Employee Data Analysis

## Tools Used
- Python
- Pandas
- Matplotlib

## Project Objectives
- Clean data
- Analyze salaries
- Analyze departments
- Analyze employee distribution by city

## KPIs
- Total Salary
- Average Salary
- Highest Salary
- Lowest Salary

## Visualizations
- Number of Employees by Department
- Average Salary by Department
- Employee Distribution by City
